# Колебание по мгновенным $x$, $v$, $a$

## Суть

Уравнение движения $a = -\omega^2 x$ выполнено в каждый момент, а не только
в среднем, — поэтому одна пара $(x, a)$, снятая в произвольный момент, уже даёт
частоту: $\omega = \sqrt{-a/x}$. Дальше пара $(x, v)$ даёт амплитуду:
$$A^2 = x^2 + \frac{v^2}{\omega^2}.$$
Это тождество $\cos^2\varphi + \sin^2\varphi = 1$, оно же закон сохранения энергии,
записанный в координатах. Фаза в тот же момент — из $\cos\varphi = x/A$ и
$\sin\varphi = -v/(A\omega)$: три числа, снятые в один момент, задают колебание
целиком.

## Триггер

«В некоторый момент времени смещение равно ..., скорость ..., ускорение ...» —
мгновенные значения разной природы, а сам момент не назван. Признак посильнее:
среди данных есть ускорение вместе со смещением — их отношение и есть $\omega^2$.

## Границы применимости

Гармоничность обязательна: $a = -\omega^2 x$ — определение гармонического колебания.
Знаки $a$ и $x$ должны быть противоположны, иначе либо движение не гармоническое,
либо в условии ошибка. Для фазы одного $\operatorname{tg}\varphi = -v/(\omega x)$
мало — он не различает четверти; нужны знаки косинуса и синуса по отдельности.

## Типичная ошибка

Искать фазу через арктангенс и потерять четверть: при $x > 0$, $v > 0$ фаза лежит
в четвёртой четверти, а арктангенс отрицательного числа даёт её же, но при
$x < 0$, $v < 0$ он выдаст то же самое значение, а фаза уже во второй. Вторая ошибка —
подставить в формулу амплитуды $v$ без деления на $\omega$.

## Пример

$x = 3$ см, $v = 8$ см/с, $a = -12$ см/с$^2$: $\omega^2 = 12/3 = 4$, $\omega = 2$ рад/с,
$A = \sqrt{9 + 16} = 5$ см. Фаза: $\cos\varphi = 0{,}6$, $\sin\varphi = -0{,}8$ —
четвёртая четверть.
