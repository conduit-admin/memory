# Физика

С октября 2026 года физика ведётся листками: подготовка к Всеросу, 11 класс.
План — [[plan]].

## Что где

- `plan.md` — план подготовки: модули по неделям, замеры, статус
- `listki/serii/` — серии задач по модулям
- `listki/razbory/` — разборы к сериям, только после решения
- `listki/eksperiment/` — холодный прогон архивных задач, псевдопраки, «почему»
- `listki/teoriya/` — сводки теории по модулям
- `sbornik.md` — сборник МОШ: карта страниц и что из него уже решено
- `sbornik.pdf` — сам сборник; наружу не публикуется, книга под копирайтом МЦНМО
- `arhiv/` — разборы задач и база приёмов по прежней схеме, до 2026-10-01.
  Больше не ведутся и на сайт не идут

Листок — это исходник `.tex`, рисунки в `<листок>_figs.tex` и собранный `.pdf`
рядом. Общая преамбула — `preamble-listok.tex` здесь, в корне раздела.
Источники и ответы к серии появляются вместе с разбором.

Архив заданий ВсОШ по физике — `tex/reference/vsosh-fizika/`.

## Именование

Номер модуля из плана и тема: `01-elektrostatika.tex` в сериях,
`01-elektrostatika-teoriya.tex` в теории, `01-elektrostatika-razbor.tex`
в разборах. Эксперимент нумеруется по неделям: `01-eksperiment.tex`.
