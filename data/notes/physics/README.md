# Физика

С октября 2026 года физика ведётся листками: подготовка к Всеросу, 11 класс.
План — [[plan]].

## Что где

- `plan.md` — план подготовки: расписание по неделям, что выдано, замеры
- `listki/serii/` — тематические листки: по 2–3 на тему
- `listki/raznoboy/` — разнобой: пройденное вперемешку
- `listki/razbory/` — разборы к листкам, только после решения
- `listki/eksperiment/` — холодный прогон архивных задач, псевдопраки, «почему»
- `listki/teoriya/` — полные сводки теории по темам
- `sbornik.md` — сборник МОШ: карта страниц и что из него уже решено
- `sbornik.pdf` — сам сборник; наружу не публикуется, книга под копирайтом МЦНМО
- `arhiv/` — разборы задач и база приёмов по прежней схеме, до 2026-10-01.
  Больше не ведутся и на сайт не идут

Листок — это исходник `.tex`, рисунки в `<листок>_figs.tex` и собранный `.pdf`
рядом. Общая преамбула — `preamble-listok.tex` здесь, в корне раздела.
Источники и ответы к листку появляются вместе с разбором.

Архив заданий ВсОШ по физике — `tex/reference/vsosh-fizika/`.

## Именование

- Тематический листок — тема и номер внутри темы: `elektrostatika-1.tex`.
  На сайте листки одной темы так и стоят рядом.
- Разнобой — сквозной номер по порядку выдачи: `raznoboy-01.tex`.
- Разбор — имя листка с `-razbor`: `elektrostatika-1-razbor.tex`.
- Теория — тема с `-teoriya`: `elektrostatika-teoriya.tex`.
- Эксперимент — по неделям: `eksperiment-01.tex`.

Задачи внутри листка нумеруются с единицы.
