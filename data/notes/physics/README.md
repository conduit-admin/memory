# Физика

С октября 2026 года физика ведётся сериями: подготовка к Всеросу, 11 класс.
План и ритм — [[plan]].

## Что где

- `plan.md` — план подготовки: ритм, серии по датам, замеры
- `listki/serii/` — серии, по одной на выдачу
- `listki/razbory/` — разборы к сериям, только после сдачи решений
- `listki/teoriya/` — сводки теории по темам, только по пройденному
- `sbornik.md` — сборник МОШ: карта страниц и что из него уже решено
- `sbornik.pdf` — сам сборник; наружу не публикуется, книга под копирайтом МЦНМО
- `arhiv/` — разборы задач и база приёмов по прежней схеме, до 2026-10-01.
  Больше не ведутся и на сайт не идут

Листок — это исходник `.tex`, рисунки в `<листок>_figs.tex` и собранный `.pdf`
рядом. Общая преамбула — `preamble-listok.tex` здесь, в корне раздела.

Архив заданий ВсОШ по физике — `tex/reference/vsosh-fizika/`.

## Именование

- Серия — сквозной номер по порядку выдачи: `seriya-01.tex`. Тематическая
  она или разнобой — видно по названию в самом листке.
- Разбор — имя серии с `-razbor`: `seriya-01-razbor.tex`.
- Теория — тема с `-teoriya`: `elektrostatika-teoriya.tex`.

Задачи внутри серии нумеруются с единицы.
