# Палочка на n кусков

## Текст

### StickPromise
— Сломаем палочку в двух случайных местах.
— С какой вероятностью из кусков сложится треугольник?
— Неравенство треугольника для каждой стороны равносильно тому, что она короче половины.

### StickSlide
— x — левый разлом, y — правый.

### CutsPlane
— Каждому исходу — точка (x, y).
— Раз x < y, она лежит над диагональю — в треугольнике.
— Распределена она равномерно, и вероятность — доля площади.
— Каждое условие режет треугольник по средней линии.
— Отсечённый угол подобен исходному треугольнику с коэффициентом 1/2 — четверть площади.
— Углы не пересекаются: длиннее половины бывает только один кусок.
— Остаётся средний треугольник — вероятность 1/4.

### MorePieces
— Третий разлом z — точка поднимается в пространство, исходы заполняют тетраэдр.
— Отсечённые углы подобны тетраэдру с тем же коэффициентом — по 1/8 объёма.
— Их четыре, и остаётся октаэдр — ровно половина.
— Для n кусков условие то же, и отсекается n углов с тем же коэффициентом.
— Значит, n-угольник сложится с вероятностью 1 − n/2ⁿ⁻¹.
