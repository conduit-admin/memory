# Telegram: канал и посты

Telegram-канал — место, куда ведёт ролик: там PDF с полным разбором
и пост о занятиях. Зачем он и почему имя такое — в `README.md` этой
папки; YouTube — [[youtube]].

Разделы 1–4 делаются один раз. Раздел 5 — с каждым роликом.

Записано 05.10.2026, до заведения канала. Что разошлось с реальностью —
поправить здесь.

## 1. Личный аккаунт — сначала защита

Канал принадлежит личному аккаунту Telegram: украдут аккаунт — уйдёт
и канал. А ученики будут писать в личку, поэтому профиль увидят
посторонние.

Настройки → Конфиденциальность:

- **Облачный пароль** — включить, с резервной почтой. Без него
  аккаунт держится на одном SMS.
- **Номер телефона → «Никто».** Кто может найти по номеру →
  «Мои контакты».
- Имя пользователя (`@ник`) в профиле — то, что даётся ученикам
  для связи. Если нынешний не хочется показывать — завести другой.

## 2. Создание канала

- Телефон: карандаш или значок нового сообщения → «Создать канал».
  Компьютер: меню ☰ → «Создать канал».
- Название: **Лучезарность**.
- Описание (до 255 знаков), черновик:

  ```
  Олимпиадная математика и физика. Полные разборы к роликам — в PDF.
  Занятия — в закреплённом посте.
  YouTube: youtube.com/@lutchezarnost
  ```

  В описании Telegram ссылки нажимаются.
- Фото — то же, что на YouTube. Пока логотипа нет, без фото.
- Тип — **публичный**, ссылка `t.me/lutchezarnost`.
- Добавить подписчиков — пропустить.

## 3. Настройки канала

Профиль канала → «Изменить».

- Подписывать сообщения — **выключено**: автор поста не показывается.
- Запретить копирование — **выключено**: разборы должны пересылаться.
- Реакции — оставить.
- Обсуждение (группа для комментариев) — пока не заводить: это ещё
  одно место, за которым надо следить.

## 4. Два закреплённых поста

Публикуются до первого ролика.

1. **О занятиях.** Что готовишь, для каких классов, онлайн или очно,
   цена — если указывать, и куда писать: `@ник`. Номер телефона
   не писать.
2. **Оглавление разборов.** Строка на ролик: вопрос из заголовка —
   ссылка на пост с PDF. Пока пусто — одна строка «Разборы появятся
   здесь». Дополняется с каждым роликом (раздел 5); пост в канале
   можно править сколько угодно.

Закреплять: долгое нажатие на пост → «Закрепить». Сначала «О занятиях»,
потом оглавление: последний закреплённый виден наверху первым,
а приходят сюда в основном за разбором.

## 5. Каждый ролик

Тем же часом, когда шортс открыт на YouTube. PDF разбора к этому
моменту должен быть готов: на него ведёт закреплённый комментарий.

1. **Пост с роликом.** Тот же экспортированный mp4 — отправлять
   как видео, не как файл; если Telegram предлагает качество —
   максимальное. Подпись:
   - вопрос из заголовка;
   - условие в одну-две строки — то же, что в описании на YouTube;
   - ссылка на шортс.
2. **Сразу следом — PDF** файлом, подпись «Разбор: <вопрос>». Видео
   и файл в один пост Telegram не собирает.
3. **Оглавление:** долгое нажатие на пост с PDF → «Копировать ссылку» →
   дописать строку в закреплённое оглавление.
4. На YouTube закреплённый комментарий — текстом: «Полный разбор —
   в Telegram: lutchezarnost». Ссылки в шортсах не нажимаются,
   см. [[youtube]], раздел 7.

Других постов нет. Каждый новый вид поста — работа ещё десять раз
в месяц; заводить его — отдельным решением.
