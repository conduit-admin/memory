# Анимации

Файл на ролик, внутри несколько `Scene`, склейка снаружи.

- `butterfly.py` — бабочка и теорема Дезарга об инволюции (5 сцен)
- `inertia.py` — момент инерции, теорема Лагранжа–Якоби (4 сцены)
- `planar.py` — раскраска карты в 5 цветов: «Страна Z», индукция, цепи Кемпе
- `rotating_liquid.py` — вращающаяся жидкость, параболоид, оптическое свойство (3D + сечение)
- `squared_rectangle.py` — разрезание прямоугольника на квадраты
- `projects/` — карточка ролика: о чём, какой файл, на какой стадии
  и `video` — ссылка на готовый ролик
- `backups/` — копия перед крупной переделкой, имя `<файл>_<ГГГГ-ММ-ДД>_<что было до>.py`
- `kanal/` — что происходит с роликом после рендера: очередь выпуска,
  правила монтажа и звука, банк тем, дикторские тексты
- `styles/` — стили, файл на стиль. Пока один — «Вертикаль»: палитра, формат
  кадра, темп, сборка формул, концовка

Формат везде вертикальный, 9:16 под Shorts.

Отладка `manim -pql`, финал `manim -qh`.

Каталог `media/` в git не попадает: рендер весит десятки мегабайт. Готовый ролик
живёт снаружи — Google Drive, YouTube, что удобнее, — а в карточке стоит только
ссылка в поле `video`. На сайте она становится кнопкой, и в списке у такого ролика
появляется метка «видео».
