# Палочка на n кусков

## О чём

Палку ломают в $n-1$ случайных местах. С какой вероятностью из обломков
складывается $n$-угольник? Складывается, когда каждый обломок короче
половины, и ответ $P_n = 1 - \dfrac{n}{2^{n-1}}$: для трёх кусков $1/4$,
для четырёх $1/2$, с ростом $n$ — к единице.

Геометрическая вероятность. Два разлома — точка квадрата, три — точка куба.
Если упорядочить разломы, исходы заполняют симплекс, а случаи «обломок
не короче половины» — его углы, каждый — копия симплекса с коэффициентом
$1/2$. Углов $n$, и друг с другом они не пересекаются: длинный обломок
бывает только один.
