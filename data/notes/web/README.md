# Веб

Задача редкая, поэтому здесь же держать заметки «как я это делал в прошлый раз»,
а не только код. Экономит вечер при каждом возвращении.

- `projects/` — карточка сайта: о чём он, где лежит, ссылки
- `styles/` — стили, файл на стиль. «Бумага» — у «Лучезарности» с 08.10.2026
  и у сайта класса 11-1 с 10.10.2026;
  «Стекло» — у кондуитов: подложка, стекло,
  цвет, движение

Сами сайты живут отдельными репозиториями со своими ремоутами, сюда не тянутся.

## Поля карточки

`repo` — владелец и имя репозитория. `ssylka` — адрес самого сайта.
`redaktor` — адрес страницы правки, если она есть. `znachok` — значок
сайта в списке, путь к картинке от корня хранилища: обычно его фавикон,
скопированный в `assets/web/<слаг>.svg`. Нет поля — в списке стоит
глобус.

Редактор стоит отдельным полем, потому что с главной страницы туда не попасть:
она про него не знает. Читать кондуит может кто угодно, писать — только владелец
репозитория, и ссылка на правку на публичной странице была бы приглашением,
которое ни для кого не работает.
