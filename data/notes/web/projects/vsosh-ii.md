# ВсОШ по ИИ

Сайт курса подготовки к олимпиаде по искусственному интеллекту — чтобы
делиться им с товарищами. Одна страница: серии, теория и проверка
решений. Строка листка сразу открывает PDF, строка архива скачивает
проверку. Заведён 20.10.2026, первыми выложены серия 1 «Школьный этап»
и теория «Данные и метрики».

## Что на нём и как туда попадает

Без списка: на сайт идёт всё из `ml/listki/` и проверка из `ml/kontest/`.
Листки курса для того и делаются, чтобы ими делиться, а ответы
и генераторы серий лежат в служебной части хранилища и наружу
не попадают.

- **Разделы** — подпапки `ml/listki/`: «Серии», «Теория». Новая подпапка
  появится следом своим разделом, заголовок — из её README или по имени.
- **Листок и то, что к нему** — `X.pdf` и `X-что-угодно.pdf` в одной
  подпапке — встают одной раскрывающейся группой, как на 11-1. Так
  к серии встанет её разбор.
- **Название** — из самого PDF: «Серия 1. Школьный этап» на сайте
  становится «Школьный этап» с подписью «Серия 1 · 16 задач». Число
  задач берётся из проверки серии.
- **Проверка решений** — архив `kontest.zip`: `kontest.py`, README
  и папки серий с данными и тестами. Баллов в архиве нет, поэтому новый
  архив распаковывается поверх старого и чужие результаты не затирает.
  Под архивом — тот же README, свёрнутый: установка, как сдавать, правила.
  Инструкция пишется одним файлом, `ml/kontest/README.md`, и на сайте
  показывается он же.

Обновить — одна команда из корня хранилища:

```
python .claude/meta/push-vsosh-ii.py [--dry-run | --local]
```

Она копирует листки, рисует миниатюры с обложек, собирает архив,
пишет индекс, коммитит и пушит. Без изменений коммита не будет: архив
собирается побайтно одинаково. `--local` пишет всё в клон сайта без
коммита — посмотреть превью `vsosh-ii-pk` до выкладки.

## Как устроен

Как 11-1, оттуда и взят код: сборки нет, страница читает
`data/index.json` прямо в браузере. Код — `index.html` и `assets/` —
правится руками, `data/` — только скриптом. Оформление — [[bumaga]].

Своего логотипа пока нет: слева в шапке название словами, справа знак
«Лучезарности», значок на телефоне — тоже знак. В «Сайтах» на
«Лучезарности» у строки пока глобус.

Инструкцию разбирает marked с cdnjs — та же версия, что на
«Лучезарности». Не загрузится — README покажется простым текстом.

Поисковикам сайт закрыт (`robots.txt` и `noindex`), автор коммитов —
адрес вида `…@users.noreply.github.com`.
