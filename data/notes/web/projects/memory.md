# Хранилище

Этот самый сайт. Читалка базы знаний: листки по физике, серии матцентра,
карточки проектов, конспекты в PDF. Открывается по ссылке с любого устройства, ставить ничего не надо.

## Зачем он есть

Заметки лежат обычными файлами в приватном репозитории. Смотреть их можно было
либо в редакторе за компьютером, либо через GitHub в браузере — первое требует
стола, второе не умеет ни вики-ссылок, ни формул. Сайт снимает вопрос: открыл
ссылку, и вся база под рукой.

## Как устроен

Сборки нет. Pages раздаёт репозиторий как есть, страница читает данные прямо
в браузере, формулы верстает KaTeX, markdown разбирает marked. Ни Node, ни
Actions, ни ожидания пайплайна.

Репозитория два, и это принципиально. `knowledge` приватный: в нём заметки,
работы и служебное. `memory` публичный: в нём код сайта и **копия** человеческой
зоны, собранная скриптом. История git публикуется целиком, поэтому приватное
и публичное разведены не аккуратностью, а устройством: наружу физически уезжает
только то, что скрипт скопировал по белому списку.

## Что умеет

Пять вкладок: проекты, физика, математика, ИИ, роли. Формулы и вики-ссылки,
обратные ссылки — под заметкой видно, какие заметки ссылаются на неё. PDF,
тёмная тема, установка на домашний экран.

Длинные списки свёрнуты: зачёт — по разделам, репетиторство — по темам,
каждая группа раскрывается отдельно и запоминается открытой. Наверху
вкладки «Проекты» — оглавление блоков.

Графа, поиска и правки из браузера нет намеренно: пока база маленькая, ни одно
из трёх не нужно, а поддерживать пришлось бы всё.

## Как обновляется

Сам по себе — никогда. Изменилось что-то в `knowledge` — витрина пересобирается
и уезжает одной командой. Стиль — [[steklo]].
