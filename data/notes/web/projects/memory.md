# Лучезарность

Этот самый сайт, по имени канала; до 07.10.2026 назывался «Хранилище». Читалка базы знаний: листки по физике, серии матцентра,
карточки проектов, конспекты в PDF. Открывается по ссылке с любого устройства, ставить ничего не надо.

## Зачем он есть

Заметки лежат обычными файлами в приватном репозитории. Смотреть их можно было
либо в редакторе за компьютером, либо через GitHub в браузере — первое требует
стола, второе не умеет ни вики-ссылок, ни формул. Сайт снимает вопрос: открыл
ссылку, и вся база под рукой.

## Как устроен

Сборки нет. Pages раздаёт репозиторий как есть, страница читает данные прямо
в браузере, формулы верстает KaTeX, markdown разбирает marked. Ни Node, ни
Actions, ни ожидания пайплайна.

Репозитория два, и это принципиально. `knowledge` приватный: в нём заметки,
работы и служебное. `memory` публичный: в нём код сайта и **копия** человеческой
зоны, собранная скриптом. История git публикуется целиком, поэтому приватное
и публичное разведены не аккуратностью, а устройством: наружу физически уезжает
только то, что скрипт скопировал по белому списку.

## Что умеет

Пять вкладок: проекты, физика, математика, ИИ, роли. Формулы и вики-ссылки,
обратные ссылки — под заметкой видно, какие заметки ссылаются на неё. PDF,
тёмная тема, установка на домашний экран.

Длинные списки свёрнуты: репетиторство — по темам, статьи — по проектам,
каждая группа раскрывается отдельно и запоминается открытой. Наверху
вкладки «Проекты» — оглавление блоков и пять последних изменённых файлов.

Вкладка «ИИ» с 23.10.2026 — тот же вид курса, что на его сайте
[[vsosh-ii]]: наверху трейлы задач, строка на трейл с картинкой, числом
задач и метками; по нажатию — сам трейл, `#/t/<трейл>`: пилюли трейлов,
метки-кнопки, задачи раскрывающимися карточками с условием и формулами.
Задачи `tools/publish.py` разбирает из условий трейлов,
`ml/kontest/<трейл>/usloviya.md`, в `data/treyly.json`; файлов задач
на витрине нет — они ссылками на сайт курса, его адрес — поле `ssylka`
карточки. Ниже — теория: урок и шпаргалка к нему одной группой с подписью
вида из поля «Название» PDF; так же подписаны и в «Актуальном». Блока
«Серии» больше нет — серий нет.

Любой файл открывается с первого нажатия, сайт — тоже. Рядом с каждым
PDF — кнопка «Скачать»: файл сохраняется под своим названием, например
«Неравенства. Разбор занятия 1.pdf». Поиск — по названиям,
по всем вкладкам сразу. У документов A5 в списке стоит миниатюра обложки.

Графа и правки из браузера нет намеренно: ни то ни другое не нужно,
а поддерживать пришлось бы всё.

## Как обновляется

Сам по себе — никогда. Изменилось что-то в `knowledge` — витрина пересобирается
и уезжает одной командой. Стиль — [[bumaga]], до 08.10.2026 был [[steklo]].
