# Кондуит

Учёт плюсов на математической смене: кондуиты по дням, общий рейтинг и пересчёт
рейтинга по любому подмножеству серий и тем.

Вес задачи — $\max(n - k,\, 1)$, где $k$ — число решивших. Задача, которую сдали
трое из двадцати четырёх, стоит 21 балл; задача, которую сдали все, — один балл:
она всё-таки была решена.

Сервера и базы данных нет. Страница читает файлы из `data/` и считает всё
в браузере читателя. Читать может кто угодно по ссылке, писать — только владелец
репозитория.
