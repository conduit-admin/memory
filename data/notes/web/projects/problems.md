# Банки задач

Банки задач для учеников: задачи одной темы из олимпиад, вступительных
и задачников, каждая с точным источником и ответом. Заведён 02.11.2026,
первым выложен банк задач с параметром — шесть источников, от Физтеха
до problems.ru.

## Что на нём и как туда попадает

Без списка: на сайт идёт каждый файл банка из `tutoring/bank/<тема>/` —
тот, у кого во фронтматтере `type: bank`. Файл — один источник, тема —
одна папка, название банка — заголовок её README. Новый источник и новая
тема появляются сами, без правки страницы. Конспекты теории, которые
лежат в тех же папках, наружу не идут.

Банк показывается целиком, сверху вниз по источникам, с фильтром
по источнику. Адрес помнит выбор: `#parametr` — банк, `#parametr/ommo` —
только ОММО. Решение задачи свёрнуто под условием и раскрывается нажатием.

Обновить — одна команда из корня хранилища:

```
python .claude/meta/push-banki.py [--dry-run | --local]
```

Она разбирает файлы банков в `data/banki.json`, коммитит и пушит.
Без изменений в банках коммита не будет. `--local` пишет в клон сайта
без коммита — посмотреть превью `problems-nout` до выкладки.

## Как устроен

Как 11-1 и сайт курса: сборки нет, страница читает `data/banki.json`
прямо в браузере, формулы верстает KaTeX, markdown разбирает marked.
Код — `index.html` и `assets/` — правится руками, `data/` — только
скриптом. Оформление — [[bumaga]]: муар, платиновые плашки, листы
в чёрной обводке. Поисковикам сайт закрыт, как и остальные.

В шапке, как на 11-1, два знака и ни слова рядом: слева логотип,
справа знак «Лучезарности»; нажатие на знак — вспышка лучей.
Логотип — «Фасад» (02.11.2026): фронтон с пустым тимпаном, архитрав,
четыре колонны и две ступени, одним чёрным, без подложки. Банк
в прямом смысле. Выбран из четырёх: «Картотека» (девять ячеек, одна
залита), «Стопка» (три листа с ответом внизу), «Семейство» (пучок
парабол из одной вершины — отсылка к параметру). Значок вкладки —
тот же рисунок с колоннами толще, на тёмной вкладке он белый;
иконки для домашнего экрана — на белом квадрате.
