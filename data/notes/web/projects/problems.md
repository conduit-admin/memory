# Банки задач

Банки задач для учеников: задачи одной темы из олимпиад, вступительных
и задачников, каждая с точным источником и ответом, и конспекты учебников
по той же теме. Заведён 02.11.2026, первым выложен банк задач
с параметром — шесть источников, от Физтеха до problems.ru, — и в тот же
день конспекты Горнштейна и Пратусевича.

## Что на нём и как туда попадает

Устроен как сайт курса ВсОШ по ИИ: главная — список, по строке — своя
страница. На главной раздел на тему, пока один — «Параметры», в нём две
строки, «Задачи» и «Учебники». У темы те же две вкладки, пилюлями
наверху; назад на главную — пилюля «Все темы».

Без списка: тема — папка `tutoring/bank/<тема>/`, и всё нужное в ней
находится само, по фронтматтеру. Файл с `type: bank` — один источник
задач, вкладка «Задачи». Файл с `type: konspekt` — конспект учебника,
вкладка «Учебники»: строка с названием конспекта и учебником под ним,
по нажатию — сам конспект листом, как заметка на «Лучезарности».
Конспект показывается как есть, формулами того же KaTeX; учебник —
из поля `istochnik`. Название темы — заголовок README папки, имя раздела
на главной — поле `razdel` того же README. Новый источник, новый
конспект и новая тема появляются сами, без правки страницы.

Наружу идут только сами конспекты, markdown. Книги под копирайтом:
сканы и всё из `tex/reference/` на сайт не попадают, в конспектах
на них только ссылки текстом.

Банк показывается целиком, сверху вниз по источникам, с фильтром
по источнику — пилюлями; на телефоне они идут одной строкой
с прокруткой вбок, как оглавление на «Лучезарности». Адрес помнит
выбор: `#parametr` — банк, `#parametr/ommo` — только ОММО,
`#parametr/uchebniki` — учебники, `#parametr/uchebniki/<файл>` — конспект.

Карточка задачи в покое — одно условие в рамке, больше ничего: банк
листают, чтобы собрать подборку, и всё лишнее между условиями мешало.
На телефоне страница стала втрое короче. Нажатие на условие раскрывает
остальное: код и источник, ответ, свёрнутые пару и решение, справку.
Выделить условие мышью, чтобы скопировать, можно — карточка от этого
не раскрывается. «Проверка» и «Теги» в справку не идут — это рабочая
кухня банка. На плашке источника — и задачи, и записи, например
«90 задач в 69 записях»: пара считается второй задачей той же записи.

Фильтра по меткам пока нет: нынешние теги банка для него не годятся,
метки будут свои.

Код задачи в раскрытой карточке — ссылка на неё: нажал, и адрес вида
`#parametr/ФТ-2026-в1-7` можно отправлять, страница откроется
с раскрытой задачей. Формулы верстаются по мере прокрутки, а не все
полторы тысячи разом: на телефоне это были секунды и десятки тысяч
узлов страницы. Пока карточка далеко, формула лежит исходником,
поэтому поиск браузера по странице находит и её.

Ученикам ссылку лучше слать через
https://conduit-admin.github.io/problems/open.html — она открывает
сайт в Chrome, а не во встроенном браузере мессенджера; тот же файл,
что у 11-1. Ссылка на задачу через него теряет код задачи.

Обновить — одна команда из корня хранилища:

```
python .claude/meta/push-banki.py [--dry-run | --local]
```

Она разбирает файлы банков в `data/banki.json`, кладёт конспекты
в `data/uchebniki/<тема>/` — эту папку переписывает целиком, так что
снятый конспект с сайта уходит, — коммитит и пушит. Без изменений
коммита не будет. `--local` пишет в клон сайта
без коммита — посмотреть превью `problems-nout` до выкладки.

## Как устроен

Как 11-1 и сайт курса: сборки нет, страница читает `data/banki.json`
и конспекты прямо в браузере, формулы верстает KaTeX, markdown разбирает
marked. Сайт — одна страница, разделы различаются адресом после «#».
Код — `index.html` и `assets/` — правится руками, `data/` — только
скриптом. Оформление — [[bumaga]]: муар, платиновые плашки, листы
в чёрной обводке. Поисковикам сайт закрыт, как и остальные.

В шапке, как на 11-1, два знака и ни слова рядом: слева логотип,
справа знак «Лучезарности»; нажатие на знак — вспышка лучей.
Логотип — «Фасад» (02.11.2026): фронтон с пустым тимпаном, архитрав,
четыре колонны и две ступени, одним чёрным, без подложки. Банк
в прямом смысле. Выбран из четырёх: «Картотека» (девять ячеек, одна
залита), «Стопка» (три листа с ответом внизу), «Семейство» (пучок
парабол из одной вершины — отсылка к параметру). Значок вкладки —
тот же рисунок с колоннами толще, на тёмной вкладке он белый;
иконки для домашнего экрана — на белом квадрате.
