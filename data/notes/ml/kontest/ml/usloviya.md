# Задачник «ML»

Задачи на данные: таблицы в pandas, массивы и функции в numpy, дальше —
модели. Список только растёт: новые задачи дописываются в конец, номера
не меняются. Сдача — через `kontest.py` из архива с проверкой,
установка — в его `README.md`. Номер задачи — `ml` и число, пункт —
латинской буквой:

```
python kontest.py ml3a 512
python kontest.py ml10a answer.csv
python kontest.py ml22 pairwise.py
python kontest.py itog ml
```

## Как сдавать

- Пункт а) задачи `ml3` сдаётся как `ml3a`, б) — `ml3b`, в) — `ml3c`.
- Файлы задачи лежат в архиве в папке `ml/dannye/` под её номером:
  у `ml3` — `ml/dannye/ml3/`. На сайте они — ссылками под условием.
- Число с дробной частью пишут через точку или запятую. Округляй, только
  если условие просит, и тогда округляй сам.
- Ответ файлом — CSV с заголовком ровно как в условии, по строке
  на значение, порядок строк любой.
- У задачи с ответом засчитывается последняя посылка, у функции — лучшая.
- Условия написаны так, чтобы правило было одно. Если что-то можно понять
  двояко — перечитай условие: ответ на это в нём.
- Массивы `.npz` читаются так:

  ```
  d = np.load("ocenki.npz")
  o = d["o"]
  ```

- Функция — файл `.py` с одной функцией, имя и аргументы как в условии;
  печатать и читать ничего не нужно. Аргументы — массивы numpy и целые
  числа, вернуть можно массив или список. Входные массивы менять нельзя:
  такая проверка не засчитывается. Балл — доля пройденных проверок, их
  около десятка; примеры из условия баллов не дают. Ограничение —
  2 секунды на проверку. Проверке нужен numpy: запускай `kontest.py` тем
  питоном, где он стоит.

## Метки

- **pandas** — таблицы CSV; удобнее всего pandas.
- **чистка** — одна таблица, записанная небрежно: числа, даты и названия
  в ней пишут по-разному. Сначала приведи их к одному виду, потом считай.
- **группы** — таблицы аккуратнее, зато их несколько, и ответ
  складывается из групп, соединений и соседних строк.
- **numpy** — массивы: ответы по файлам `.npz` или функции.
- **функция** — сдаётся файл с функцией, проверка вызывает её сама.
- **без циклов** — полный балл только без циклов: если в файле есть
  `for`, `while`, comprehension, `map` или `np.vectorize`, больше
  половины баллов не будет.

## ml9. Ученики и баллы

Метки: pandas, группы

Два файла. В `ucheniki.csv` — номер ученика, фамилия и имя, класс.
В `rezultaty.csv` — номер ученика, предмет, балл и номер попытки;
«н/я» значит, что ученик не явился, это не балл. Номер ученика в двух
файлах мог быть записан по-разному. В `rezultaty.csv` есть записи
учеников, которых нет в `ucheniki.csv`, — их не учитывайте.

Лучший балл ученика по предмету — максимум по его попыткам. Итог
ученика — среднее его лучших баллов по тем предметам, где они есть.

**а)** Сколько учеников из `ucheniki.csv` не имеют ни одной записи
в `rezultaty.csv`?

**б)** Для каждого класса найдите среднее итогов его учеников; ученики
без единого балла не учитываются. Сдайте файл `answer.csv` с заголовком
`klass,sredniy` и строкой на каждый класс, среднее округлите до сотых.

**в)** Для каждого предмета найдите среднее $m$ и стандартное отклонение
$\sigma$ лучших баллов по нему; в $\sigma$ делят на число учеников,
а не на число минус один. Сколько пар «ученик, предмет», в которых
лучший балл больше $m + 2\sigma$?

## ml13. Контест

Метки: pandas, группы

Файл `posylki.csv`: `uchastnik`, `zadacha` — буква, `minuta` — от начала
тура, `verdikt`: `OK` — принято; `WA`, `TL`, `RE` — неверно; `CE` —
ошибка компиляции. Строки перемешаны. Задача решена, если по ней есть
`OK`. Посылки после первого `OK` по задаче не учитываются, `CE` попыткой
не считается. Штраф участника — сумма по решённым задачам: минута
первого `OK` плюс 20 за каждую посылку с `WA`, `TL` или `RE` до него.
Выше в таблице тот, кто решил больше задач; при равенстве — у кого
меньше штраф; затем — ник раньше по алфавиту.

**а)** Сколько участников решили хотя бы одну задачу?

**б)** Каков штраф победителя?

**в)** По какой задаче больше всего неудачных попыток — посылок с `WA`,
`TL` или `RE` до первого `OK` — суммарно у решивших её участников?
Ответ — буква.

`vektory.npz`: `v` формы $(300, 24)$ — векторы слов, `slova` — сами
слова, коды вида `w042`, в том же порядке. Близость двух слов — косинус
угла между их векторами.

**а)** Сколько векторов длиной больше 6?

**б)** Какое слово ближе всего к `w042`, не считая его самого?

**в)** Сколько пар слов $\{a, b\}$, $a \ne b$, у которых косинус больше
$0{,}9$?

## ml21. Пропуски в ряду

Метки: numpy

`ryad.npz`: `x` — 5000 замеров через равные промежутки, `nan` — пропуск.
Первый и последний замеры есть. Участок пропусков — несколько пропусков
подряд, слева и справа от которых стоят замеры.

**а)** Сколько пропусков?

**б)** Сколько участков пропусков?

**в)** Сколько пропусков в самом длинном участке?

**г)** Заполни каждый пропуск линейно между ближайшими замерами слева
и справа, по номерам замеров. Найди среднее заполненного ряда. Ответ
округли до тысячных.

## ml22. Попарные расстояния

Метки: numpy, функция, без циклов

`pairwise_l1(X, Y)`: `X` формы $(n, d)$, `Y` формы $(m, d)$. Верни
матрицу $D$ формы $(n, m)$, где $D_{ij} = \sum_t |X_{it} - Y_{jt}|$ —
манхэттенское расстояние между $i$-й строкой `X` и $j$-й строкой `Y`.
$nmd \le 2\cdot10^6$.

```
pairwise_l1([[0, 0], [1, 2]], [[1, 1], [3, 0], [0, 2]])
→ [[2, 3, 2], [1, 4, 1]]

pairwise_l1([[0.5, -1, 2]], [[0, 0, 0], [1.5, -1, 2.5]])
→ [[3.5, 1.5]]
```

## ml23. Среднее по группам

Метки: numpy, функция, без циклов

`group_mean(values, groups, k)`: `values` — $n$ чисел, `groups` — их
группы, целые от $0$ до $k - 1$. Верни массив длины $k$: среднее
`values` в каждой группе; у группы без единого элемента — `nan`.
$n \le 10^6$, $k \le 10^5$.

```
group_mean([1, 2, 3, 4], [0, 1, 0, 1], 2)
→ [2.0, 3.0]

group_mean([5, 7, 1], [2, 2, 0], 4)
→ [1.0, nan, 6.0, nan]
```

## ml24. Скользящий максимум

Метки: numpy, функция, без циклов

`moving_max(a, w)`: `a` — $n$ чисел, $1 \le w \le n$. Верни массив длины
$n - w + 1$, где $i$-й элемент — наибольшее из $a_i, \dots, a_{i+w-1}$.
$n \le 10^6$.

```
moving_max([1, 3, 2, 5, 4], 2)
→ [3, 3, 5, 5]

moving_max([4, -1, 0.5, 0.5, 7, 2], 3)
→ [4.0, 0.5, 7.0, 7.0]
```

## ml25. Самые длинные строки

Метки: numpy, функция, без циклов

`top_k_rows(X, k)`: `X` формы $(n, d)$, $1 \le k \le n$. Верни номера $k$
строк с наибольшей евклидовой длиной, от самой длинной к короче; при
равной длине раньше идёт строка с меньшим номером. $nd \le 2\cdot10^6$.

```
top_k_rows([[3, 4], [1, 0], [0, 6], [2, 2]], 2)
→ [2, 0]

top_k_rows([[1, 0], [0, 1], [1, 1], [0, 0]], 3)
→ [2, 0, 1]
```

## ml26. Ранги

Метки: numpy, функция, без циклов

`ranks(a)`: `a` — $n$ чисел. Ранг элемента — его место, если упорядочить
числа по возрастанию, начиная с 1; у равных элементов ранг — среднее
мест, которые они занимают вместе. Верни массив рангов в порядке
элементов `a`. $n \le 10^6$.

```
ranks([30, 10, 20])
→ [3.0, 1.0, 2.0]

ranks([2, 1, 2, 3, 1])
→ [3.5, 1.5, 3.5, 5.0, 1.5]
```

## ml27. Матрица ошибок

Метки: numpy, функция, без циклов

`confusion(y_true, y_pred, k)`: истинные и предсказанные классы $n$
объектов, целые от $0$ до $k - 1$. Верни матрицу $M$ формы $(k, k)$:
$M_{ij}$ — сколько объектов класса $i$ предсказаны как класс $j$.
$n \le 10^6$, $k \le 300$.

```
confusion([0, 1, 1, 2], [0, 2, 1, 2], 3)
→ [[1, 0, 0], [0, 1, 1], [0, 0, 1]]

confusion([1, 1, 0], [0, 0, 0], 2)
→ [[1, 0], [2, 0]]
```
