# Контест: проверка серий по ИИ

Своя тестирующая система к сериям — как на олимпиаде, только дома.
Три вида задач: ответ числом или словом, ответ файлом, программа на тестах.

## Как сдавать

Из папки `ml/kontest`:

```
python kontest.py 1a 5/8              # пункт а) задачи 1
python kontest.py 6a 9 10 8 7         # ответ из нескольких чисел
python kontest.py 12b answer.csv      # ответ файлом
python kontest.py 13 reshenie.py      # программа
python kontest.py itog                # таблица баллов
```

- Пункты — латиницей: `a`, `b`, `c`; русские тоже понимаются.
- Дробь можно писать как `5/8` или `0.625`, запятая вместо точки — тоже.
  Если в условии сказано округлить — округляй сам: `4.18` и `4.180`
  засчитаются одинаково, а `4.2` — нет.
- Программа читает стандартный ввод и пишет в стандартный вывод, как
  на олимпиаде. Запускается тем же питоном, что и `kontest.py`. Нужен
  pandas или numpy — запускай из окружения, где они стоят; на ПК это
  `PycharmProjects/DataAnalysis/.venv/Scripts/python.exe`. Другой питон
  указывается ключом `--python`.
- Серия по умолчанию — последняя; другую выбирает `-s 1`.

## Правила

- **Задача с ответом — засчитывается последняя посылка**, как на ШЭ.
  Число попыток не ограничено, но результат сразу виден — на туре его
  видно только после окончания.
- **Программа — засчитывается лучшая посылка.** Балл — число пройденных
  тестов; примеры из условия идут первыми и баллов не дают. На примерах
  при ошибке показывается, что ожидалось; на остальных — только вердикт:
  `OK`, `WA` — неверный ответ, `TL` — не уложилась во время, `RE` —
  программа упала.
- **Ограничение времени — 2 секунды на тест**, на олимпиаде обычно одна:
  питон на Windows запускается медленнее, чем на сервере. Укладывайся в одну.

Баллы пишутся в `seriya-NN/rezultaty.json`, таблица — `python kontest.py itog`.

## Устройство

- `kontest.py` — сама проверка, только стандартная библиотека.
- `seriya-NN/zadachi.json` — ответы и выходы тестов хешами.
- `seriya-NN/testgen.py` — генератор входов тестов. Тесты создаются
  при первой проверке и кладутся в `.cache/`; их хеш сверяется
  с эталонным, так что на другой машине тесты те же.
- `seriya-NN/dannye/` — файлы к задачам на данные.

Хеш защищает от случайного взгляда, а не от перебора: ответ из небольшого
числа перебирается за секунду. Так что заглядывать в `zadachi.json` можно,
но бесполезно, а перебирать — нечестно.
