# Контест: проверка задач по ИИ

Своя тестирующая система к задачам курса — как на олимпиаде, только
дома. Задачи, теория и архив с проверкой — на сайте
[ВсОШ по ИИ](https://conduit-admin.github.io/vsosh-ii/).

## Установка

1. Python 3.9 или новее — [python.org](https://www.python.org/downloads/).
   На Windows при установке отметь «Add python.exe to PATH».
2. Скачай `kontest.zip` и распакуй. Работать нужно в папке, где лежит
   `kontest.py`: Windows при «Извлечь все» кладёт её внутрь ещё одной
   папки `kontest`.
3. Если решаешь задачи на данные или пишешь программы с pandas и numpy,
   поставь их; самой проверке они не нужны:

   ```
   python -m pip install pandas numpy
   ```

## Как сдавать

Открой терминал в папке с `kontest.py`:

- **Windows** — открой папку в Проводнике, щёлкни по адресной строке,
  набери `cmd` и нажми Enter. Или правый щелчок по пустому месту
  папки → «Открыть в Терминале».
- **macOS** — открой «Терминал», набери `cd ` с пробелом, перетащи папку
  в окно и нажми Enter.
- **Linux** — правый щелчок в папке → «Открыть в терминале».

Сначала проверь, что всё работает: `python kontest.py itog` должен
показать таблицу задач с нулями. Если `python` не находится или
открывает Microsoft Store, на Windows пиши `py`, на macOS и Linux —
`python3`.

Задачи живут в трёх задачниках, как три части тура: «Математика» —
чистая математика, решается на бумаге, ответ — число или пример;
«ML» — данные и модели: ответы по файлам, функции на numpy
и предсказания моделей;
«Программы» — программы на тестах. Это длинные списки, которые только
дописываются, номера в них не меняются. Номер задачи — задачник
и число: `mat7`, `ml17`, `prog5`; пункт — латинская буква: `mat7b`.

```
python kontest.py itog                # таблица баллов, все задачники
python kontest.py itog ml             # один задачник
python kontest.py itog pandas         # одна метка; можно вместе: itog ml numpy
python kontest.py mat3a 125           # ответ на пункт а) задачи mat3
python kontest.py mat1b 1/2 -0.75     # ответ из нескольких чисел
python kontest.py mat14a 1 2 3 4      # пример: проверка по свойству
python kontest.py ml9b answer.csv     # ответ файлом
python kontest.py prog5 reshenie.py   # программа
python kontest.py ml22 funkciya.py    # функция
python kontest.py ml43 predskazaniya.csv  # модель: предсказания для test
```

Условия — на сайте и в архиве, по файлу на задачник: `mat/usloviya.md`,
`ml/usloviya.md` и `prog/usloviya.md`. Файлы задачи лежат в папке
`dannye` её задачника под её номером: у `ml9` — `ml/dannye/ml9/`.

Программы и функции запускаются тем же питоном, что и `kontest.py`.
Если numpy или pandas стоят в другом окружении, укажи его питон:
`python kontest.py ml22 funkciya.py --python путь/к/python`.

## Правила коротко

- Пункты — латиницей: `a`, `b`, `c`. Дробь — `5/8` или `0.625`, можно
  с запятой. Если условие просит округлить — округляй сам.
- Несколько чисел — через пробел, в порядке из условия. Запятая между
  цифрами — десятичная: `0,6 -0,8` — это два числа. Если чисел
  не столько, сколько просит условие, посылка не принимается
  и не считается.
- Ответ файлом — CSV с заголовком ровно как в условии.
- У задачи с ответом засчитывается последняя посылка. Проверка пишет
  номер и название задачи — сверься, туда ли сдал.
- Пример — целые числа через пробел. Проверка подставляет их в условие,
  поэтому подходит любой верный пример, и отвечает только «подходит»
  или «не подходит», не говоря, что не так. Засчитывается лучшая
  посылка.
- Программа читает стандартный ввод и пишет в стандартный вывод.
  Засчитывается лучшая посылка; примеры из условия идут первыми и баллов
  не дают. Вердикты: `OK`, `WA` — неверный ответ, `TL` — дольше
  ограничения времени, `RE` — программа упала. Тесты строятся на месте
  при первой посылке задачи и лежат в папке `.cache`.
- Как считаются баллы программы. У задач «Программ» — до 100 баллов,
  ограничение времени своё, и всё это написано в условии, в строках
  «Оценка» и «Ограничение времени». Либо тесты стоят поровну — 20 тестов
  по 5 баллов, — либо разбиты на группы, как на олимпиаде: группа даёт
  свои баллы, только если пройдены все её тесты, а один `WA` или `TL`
  обнуляет её всю. Проверка печатает, сколько тестов каждой группы
  пройдено.
- Ввод бывает по 200 000 чисел: читай его разом —
  `sys.stdin.buffer.read().split()`, — а не построчно через `input()`.
- Функция — файл `.py` с функцией, имя и аргументы как в условии; читать
  и печатать ничего не нужно. Проверка сама вызывает её на своих данных
  и сравнивает результат, дробные числа — с допуском. Засчитывается
  лучшая посылка, балл — доля пройденных проверок. Вердикт `ПОРЧА` —
  функция изменила переданный ей массив. Если у задачи метка «без
  циклов», а в файле есть `for`, `while`, comprehension, `map`, `apply`
  или `np.vectorize`, баллов не больше половины.
- Модель — у задачи файлы train и validation с ответами и test без них.
  Сдаётся CSV предсказаний для test: заголовок ровно как в условии, каждый
  id из test — ровно один раз, порядок строк любой; из pandas —
  `to_csv("predskazaniya.csv", index=False)`. Проверка считает метрику
  из условия по настоящим ответам test и ставит балл по строке «Оценка»:
  результат baseline и хуже — 0, эталона и лучше — полный балл, между
  ними — линейно. Засчитывается лучшая посылка. Файл не того формата —
  другой заголовок, лишний, пропущенный или повторённый id, значение
  не того вида — не принимается и не считается. Метрики считаются так же,
  как в `sklearn.metrics`: validation можно оценить у себя. Ответы test
  лежат в архиве закодированными — подглядывать в них то же, что
  в хеши ответов: честное слово.
- Появились новые задачи — скачай архив заново и распакуй поверх старой
  папки: баллы сохранятся.

## «Математика» с 24 октября

24 октября 2026 года задачник «Математика» начат заново: в нём теперь
только чистая математика, а прежние `mat1`–`mat13` — задачи школьного
этапа и четыре программы — сняты. Под теми же номерами теперь другие
задачи. Прежние баллы `mat` при первом запуске нового архива
откладываются в `mat/rezultaty-v1.json` и в таблицу не идут; баллы
`ml` и `prog` остаются как были.
