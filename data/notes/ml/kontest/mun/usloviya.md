# Задачник «Варианты МЭ»

Настоящие варианты муниципального этапа — для пробных туров. Условий
здесь нет: у каждой задачи ссылка на оригинал, а задачник даёт только
проверку. Номера идут по вариантам, по шесть задач, в порядке заданий
варианта.

Вариант решается как тур — 180 минут подряд. На этапе ответы задач
с вводом ответа не видны до конца тура, а программы проверяются сразу,
поэтому ответы задач 1–4 сдавай после конца тура, а программы — по ходу.
В PDF вариантов I и II решение задачи идёт сразу под её условием — листай
аккуратно.

Список только растёт: новые задачи дописываются в конец, номера
не меняются. Сдача — через `kontest.py` из архива с проверкой,
установка — в его `README.md`. Номер задачи — `mun` и число, пункт —
латинской буквой:

```
python kontest.py mun3a 1/2
python kontest.py mun5 reshenie.py
python kontest.py itog mun
```

## Как сдавать

- Пункт а) задачи `mun2` сдаётся как `mun2a`, б) — `mun2b`. У задачи
  с одним ответом пункт один: `mun1a`, можно и просто `mun1`.
- Число — целое, дробь `p/q` или десятичная: `3/5`, `0.6` и `0,6` — одно
  и то же. Где ответ — число учеников, сумма целых и тому подобное, проверка
  ждёт целое.
- У задачи с ответом засчитывается последняя посылка, у программы —
  лучшая. Баллы — как на этапе: задача — 100, пункты делят их так же,
  как в оригинале.
- Таблица одного варианта — по его метке, в кавычках:
  `python kontest.py itog "Сириус III"`.
- Таблиц к заданиям 4 в опубликованных разборах нет. Поэтому файл задачи —
  свой, того же устройства, что описано в условии, и ответ считается
  по нему. Файлы лежат в архиве в папке `mun/dannye/` под номером задачи,
  на сайте — ссылками под условием.
- Программа на Python 3 читает стандартный ввод и пишет в стандартный
  вывод; ввод и вывод — как в условии оригинала. Пробелы в концах строк
  и пустые строки в конце вывода не важны.
- Тесты к программам свои. Ограничение времени — в условии задачи
  задачника, на один тест; оно поставлено по решению на Python и не меньше,
  чем у оригинала.
- Пример в условии задачника — тоже свой. Он проверяется первым и баллов
  не даёт.
- Тесты строятся на месте при первой посылке задачи и лежат в папке
  `.cache` рядом с `kontest.py`.
