# Задачник «Программы»

Программы, как на школьном и муниципальном этапах: читаешь стандартный
ввод, пишешь стандартный вывод, проверка — на тестах. Сюжеты — про
данные и модели. Список только растёт: новые задачи дописываются
в конец, номера не меняются. Сдача — через `kontest.py` из архива
с проверкой, установка — в его `README.md`. Номер задачи — `prog`
и число:

```
python kontest.py prog1 reshenie.py
python kontest.py itog prog
```

## Как сдавать

- Программа на Python 3 читает стандартный ввод и пишет в стандартный
  вывод. Пробелы в концах строк и пустые строки в конце вывода
  не важны.
- Во вводе бывает по 200 000 чисел. Читать их удобнее разом, а не
  построчно через `input()`:

  ```
  import sys
  data = sys.stdin.buffer.read().split()
  n = int(data[0])
  a = list(map(int, data[1:1 + n]))
  ```

- Балл задачи — до 100. Как он складывается, сказано в условии,
  в строке «Оценка»: либо все тесты стоят поровну, либо тесты разбиты
  на группы, и группа даёт свои баллы, только если пройдены все её
  тесты, — так считают на этапах.
- Примеры из условия проверяются первыми и баллов не дают.
- Засчитывается лучшая посылка.
- Ограничение времени — в условии задачи, на один тест. Оно поставлено
  по решению на Python.
- Тесты строятся на месте при первой посылке задачи и лежат в папке
  `.cache` рядом с `kontest.py`; большие весят по нескольку мегабайт.

## prog1. Плато потерь

Метки: ряд

Потери модели по эпохам — целые числа $a_1, \dots, a_n$. Плато —
отрезок подряд идущих эпох с равными потерями, который нельзя продлить
ни влево, ни вправо: соседние с ним эпохи, если они есть, имеют другие
потери. Одна эпоха тоже может быть плато.

Соседи плато — эпоха сразу перед его первой эпохой и эпоха сразу после
его последней. У плато, которое начинается с первой эпохи ряда, соседа
слева нет; у плато, которое кончается последней эпохой, нет соседа
справа. Плато — минимум, если у него есть хотя бы один сосед и у каждого
его соседа потери больше, чем на плато. Плато на весь ряд соседей
не имеет и минимумом не считается.

Найдите все плато-минимумы.

**Ввод.** В первой строке $n$ ($1 \le n \le 2\cdot 10^5$), во второй —
$a_1, \dots, a_n$ ($|a_i| \le 10^9$).

**Вывод.** В первой строке — число плато-минимумов $k$. Если $k > 0$,
во второй строке — номера их первых эпох по возрастанию через пробел;
эпохи нумеруются с единицы.

**Оценка.** 20 тестов, каждый — 5 баллов. В 12 тестах из 20
$n \le 2000$.

**Ограничение времени** — 1 с на тест.

```ввод
10
5 3 3 4 4 2 2 2 6 6
```

```вывод
2
2 6
```

```ввод
4
1 2 2 1
```

```вывод
2
1 4
```

## prog2. Лишние признаки

Метки: ряд

У каждого из $n$ объектов $m$ двоичных признаков, и записаны они одним
числом: объекту $i$ соответствует целое $x_i$, $0 \le x_i < 2^m$,
а признак $j$ объекта $i$ ($j = 0, 1, \dots, m - 1$) — это бит $j$
числа $x_i$, то есть $\lfloor x_i / 2^j \rfloor \bmod 2$.

Признак бесполезен, если у всех объектов он одинаков. Два признака
дублируют друг друга, если либо у каждого объекта они равны, либо
у каждого объекта они различны. Сначала выбрасывают все бесполезные
признаки. Оставшиеся разбиваются на группы: в одной группе любые два
признака дублируют друг друга, из разных групп — нет. Из каждой группы
оставляют один признак. Сколько признаков останется?

**Ввод.** В первой строке $n$ и $m$ ($1 \le n \le 10^5$,
$1 \le m \le 30$), во второй — $x_1, \dots, x_n$.

**Вывод.** Одно число — сколько признаков останется.

**Оценка.** 20 тестов, каждый — 5 баллов. В 12 тестах из 20
$n \le 2000$.

**Ограничение времени** — 1 с на тест.

```ввод
4 3
5 3 4 2
```

```вывод
2
```

```ввод
3 4
1 9 3
```

```вывод
2
```

## prog3. Терпение

каждой эпохи $i$ найдите, сколько эпох прошло с последней эпохи, где
потери были строго меньше: это $i - j$, где $j$ — наибольший номер,
для которого $j < i$ и $a_j < a_i$. Если такого $j$ нет, ответ для
эпохи $i$ равен $i$.

**Ввод.** В первой строке $n$ ($1 \le n \le 2\cdot 10^5$), во второй —
$a_1, \dots, a_n$ ($|a_i| \le 10^9$).

**Вывод.** $n$ чисел через пробел — ответы для эпох $1, 2, \dots, n$.

**Оценка.** 20 тестов, каждый — 5 баллов. В 12 тестах из 20
$n \le 2000$.

**Ограничение времени** — 1 с на тест.

```ввод
5
4 2 5 3 6
```

```вывод
1 2 1 2 1
```

## prog4. Сглаживание голосованием

Метки: ряд

Модель предсказала классы $b_1 b_2 \dots b_n$ — строку из нулей
и единиц. Предсказания сглаживают с радиусом $r$: сглаженное значение
$s_i$ — то, которого больше среди $b_j$ для всех $j$ с $|j - i| \le r$
и $1 \le j \le n$. Сама позиция $i$ в их числе; у краёв строки таких
позиций меньше, чем $2r + 1$. Если нулей и единиц среди них поровну,
$s_i = b_i$. В скольких позициях сглаженное значение отличается
от исходного?

**Ввод.** В первой строке $n$ и $r$ ($1 \le n \le 2\cdot 10^5$,
$1 \le r \le n$), во второй — строка $b_1 b_2 \dots b_n$ без пробелов.

**Вывод.** Одно число — сколько номеров $i$ с $s_i \ne b_i$.

**Оценка.** 20 тестов, каждый — 5 баллов. В 12 тестах из 20
$n \le 2000$.

**Ограничение времени** — 1 с на тест.

```ввод
7 1
1101001
```

```вывод
2
```

```ввод
6 2
100011
```

```вывод
1
```

## prog5. Пары для ансамбля

Метки: ряд

Есть $n$ моделей, у модели $i$ время ответа $t_i$ и семейство $f_i$.
Ансамбль собирают из двух разных моделей разных семейств, и их общее
время не должно превышать $T$: $t_i + t_j \le T$. Сколько есть способов
выбрать такую пару? Пары неупорядоченные: $\{i, j\}$ и $\{j, i\}$ —
одна и та же пара.

**Ввод.** В первой строке $n$ и $T$ ($2 \le n \le 2\cdot 10^5$,
$1 \le T \le 2\cdot 10^9$), во второй — $t_1, \dots, t_n$
($1 \le t_i \le 10^9$), в третьей — $f_1, \dots, f_n$
($1 \le f_i \le n$).

**Вывод.** Одно число — сколько пар годятся в ансамбль.

**Оценка.** Две группы тестов; группа засчитывается, только если
пройдены все её тесты.

- группа 1 — 20 баллов: $n \le 2000$;
- группа 2 — 80 баллов: без дополнительных ограничений, в неё входят
  и тесты группы 1.

**Ограничение времени** — 1 с на тест.

```ввод
5 10
3 7 5 6 2
1 2 1 1 2
```

```вывод
4
```

## prog7. Калибровка датчиков

Метки: ряд

В ряд стоят $n$ датчиков. Датчик $i$ показывает $a_i$, а должен
показывать $b_i$. За одну операцию выбирают отрезок подряд идущих
датчиков и ко всем их показаниям прибавляют 1 или из всех их показаний
вычитают 1. Показания по ходу могут быть любыми целыми. За какое
наименьшее число операций каждый датчик станет показывать то, что
должен?

**Ввод.** В первой строке $n$ ($1 \le n \le 2\cdot 10^5$), во второй —
$a_1, \dots, a_n$, в третьей — $b_1, \dots, b_n$
($|a_i|, |b_i| \le 10^9$).

**Вывод.** Одно число — наименьшее число операций.

**Оценка.** 20 тестов, каждый — 5 баллов. В 12 тестах из 20
$n \le 100$ и все $|a_i|, |b_i| \le 100$.

**Ограничение времени** — 1 с на тест.

```ввод
4
1 2 3 4
2 4 4 3
```

```вывод
3
```

```ввод
3
0 0 0
-2 1 -2
```

```вывод
5
```

## prog10. Конвейер на k ускорителях

## prog11. Пары не в том порядке
