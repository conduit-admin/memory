# ML и программирование

`notes/` — конспекты по шаблону `templates/konspekt.md`.
Код держать рядом с конспектом, а не в отдельной куче: через полгода связь между
«я это читал» и «я это писал» теряется первой.

Правило конспекта: раздел «Зачем это нужно» пишется первым. Если он не пишется,
тему рано конспектировать.
