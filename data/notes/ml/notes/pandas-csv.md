# pandas и CSV

## Зачем это нужно

Ответ в домашке часто сдаётся CSV-файлом и проверяется построчно. Метрику
посчитать обычно легко — ломается формат: лишняя колонка, `848.0` вместо
`848`, не тот разделитель. Каждая такая мелочь обнуляет строку ответа.

## Основное

### CSV

- Это текст: строка файла — строка таблицы, значения через запятую, первая
  строка — заголовок. Типов в файле нет, их угадывает тот, кто читает.
- Смотреть как текст: Блокнот или в JupyterLab Open With → Editor.
  Просмотрщик-таблица прячет `.0`, лишние колонки и разделитель.
- Не открывать и не сохранять в Excel: с русскими настройками он пишет `;`.

### Чтение

- `pd.read_csv(path)` режет строки по разделителю, первую берёт в заголовок,
  для каждой колонки угадывает тип и добавляет свой индекс $0..n-1$.
  Настраивается через `sep`, `header=None`, `encoding`, `dtype`.
- Сразу после чтения: `df.head()`, `df.shape`, `df.dtypes`.
- Целая колонка с одним пропуском становится дробной: `nan` бывает только
  у `float`.
- В numpy: `df["col"].to_numpy()` или `np.loadtxt(path, delimiter=",",
  skiprows=1, dtype=int)`. `loadtxt` не переносит ни пропусков, ни текста.

### Запись

- `df.to_csv(path, index=False)`. Без `index=False` первой колонкой уедет
  индекс pandas.
- Число пишется по типу колонки: `float` уйдёт как `848.0`. Перед записью —
  `df.dtypes`.
- На Windows строки кончаются на `\r\n`.
- Имя файла — с расширением `.csv`.
- Проверка: готовый файл как текст, построчно с образцом.

### Новые колонки из старых

- Столбец целиком: `pd.DataFrame({"s": df["a"] + df["b"]})` или
  `df.assign(s=...)` — новая таблица, старая цела. Считает numpy, без цикла.
- `df.apply(f, axis=1)` вызывает функцию на каждой строке: медленно,
  и при смешанных типах целые приходят как `1.0`. `iterrows` — то же.
- `new = df` — не копия, а второе имя той же таблицы. Копия — `df.copy()`.
- `/` всегда даёт `float`. Деление на 0 не падает: $x/0$ даёт `inf`,
  $0/0$ даёт `nan`.
- Колонки из **разных** таблиц сопоставляются по меткам индекса, а не по
  позиции: несовпавшие метки дают `nan`, длина может вырасти.

### Группировка: строка на группу

- `df.groupby("key").agg(имя=("колонка", "sum"))` — split–apply–combine:
  разбить по ключу, посчитать в каждой группе, склеить. Индекс результата —
  значения ключа. Счёт по условию — сумма булевой колонки.
- Счётчики по разным колонкам — `value_counts()` у каждой, потом
  `pd.DataFrame({...})`: строки сойдутся по индексу.
- Группа без строк в результат не попадает: `.reindex(range(K), fill_value=0)`.
- Индекс в обычную колонку: `.rename_axis("имя").reset_index()`.

### pandas 3

- Copy-on-write: присваивание через двойные скобки, `df[a][b] = ...`,
  таблицу не меняет.
- Строковые колонки имеют тип `str`, а не `object`.
