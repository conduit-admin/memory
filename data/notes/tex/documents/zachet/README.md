# Зачёт: ответы на вопросы

Зачёт кружка 11 класса, 26 сентября 2026. Список вопросов — `voprosy.pdf`
здесь же; он разбит на подтемы, и на каждую подтему — свой документ: исходник,
файл рисунков и собранный PDF рядом.

## Устройство

Один документ — одна подтема, один параграф — один вопрос, в том же порядке
и с тем же названием, что в списке вопросов. На зачёте по номеру вопроса сразу
открывается нужный `\S`, и ради этого стоит терпеть длинные заголовки параграфов.
Перенос строки в таком заголовке ставится вручную, через `\\`: иначе TeX
рвёт слово по слогам, и в заголовке висит «Вы-числение».

На титуле — ровно название подтемы: без номера, без слова «ответы», без подзаголовков.
Титул не нумеруется, нумерация страниц идёт со следующей (`titlepage` это делает сам).

## Замечания о стиле

Общий стиль — `tex/styles/cvetnoy.md`; здесь только то, что специфично для зачётных работ.

**Ссылки идут назад.** Определением или теоремой из вопроса $n$ разрешено
пользоваться в вопросе $k$ при $k \ge n$ — так устроен список. Ссылка вперёд,
значит, ошибка, а ссылка назад пишется прямо в тексте как `\S3`: параграфов мало,
`\label`/`\ref` тут только мешают.

**Источник — конспект, а не учебник.** Формулировки и ход доказательств берутся
из конспекта кружка, даже когда в книге доказательство короче: спрашивать будут
по конспекту. Конспект — это слайды занятия в PDF; в репозитории они не лежат,
и к документу их надо иметь под рукой отдельно. Нумерация теорем в слайдах
сквозная по всему курсу, поэтому «Теорема 4» в одном разделе может означать
теорему из другого; в документ номера не переносятся, ссылки идут по `\S`.

**Пропуски в конспекте бывают двух сортов.** Верный и несложно доказуемый шаг,
который просто опущен, в документ не дописывается: о нём спрашивают после
работы, и дописывать его или нет — решение владельца. Серьёзная дыра —
формулировка не работает, доказательство не проходит, вопрос в конспекте
не разобран вовсе — чинится сразу, в самом документе: на зачёте её придётся
закрывать вслух. Таких мест обычно два-три на подтему.

**Что дописано — сначала помечается.** Пока документ черновой, всё, чего не было
в конспекте, идёт красным: `\add{...}` для вставки внутрь абзаца, заголовок
«Дописано» для целого куска, `\NB{...}` для записки самому себе. Переключатель
`\showaddtrue` / `\showaddfalse` в преамбуле гасит пометки разом, не трогая текст.
В чистовике пометки сняты, черновик уезжает в `tex/drafts/`.

**Рисунков мало.** Два-четыре на документ и только там, где картинка заменяет абзац
объяснений: чередующийся цикл, зажатие неравенством, схема вывода, сетка разбиения.
Определение иллюстрировать не надо — оно и так короткое.

**Числа на рисунках настоящие.** Координаты считаются по тем же формулам, что стоят
в тексте: столбики Фибоначчи против $\varphi^k/\sqrt5$, суммы Дарбу против графика,
длины хорд в принципе Кавальери. Нарисованное на глаз рано или поздно начинает
противоречить соседнему абзацу.

## Сборка

```
latexmk -pdf -cd tex/documents/zachet/matchings.tex
```

Все документы самодостаточны: преамбула внутри файла, общая
`tex/preamble.tex` не подключается. Флаг `-cd` всё равно обязателен — `\input`
ищется относительно текущего каталога, и без него не находится даже
`<имя>_figs.tex`.
